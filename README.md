## What it does

- **Your AI team in one window.** Describe a task in the chat; a planner splits it into steps and builder agents carry them out.
- **A living pixel office.** Every agent has a desk, so you can see at a glance who is thinking, coding or waiting.
- **Claude and Codex together.** Use your own Claude and/or Codex sign-in; Maestro runs them side by side.
- **Works on your folders.** Point it at one or several local repositories and attach files to a task.
- **Checks before it calls work done.** Lint, type checks and tests run as part of a task.

## Install

1. Download **[Maestro-Setup.exe](https://github.com/XxArDy/maestro-releases/releases/latest/download/Maestro-Setup.exe)** and run it.
2. If Windows SmartScreen warns you, click **More info**, then **Run anyway**.
3. Open Maestro, sign in to Claude and/or Codex, add a project folder and send your first task.

## Updates

Maestro checks this repository for new versions and updates itself. Every update is signed, and the app refuses one whose signature does not match. Your projects, settings and sign-ins are kept.

## About this repository

This repository only hosts Maestro's installers and update files. The source code is private.
